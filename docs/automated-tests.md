# 自動テストの運用

- GitHub Actionsで毎日06:17（日本時間、UTC 21:17）に実行します。実行は遅れる場合があります。
- main向けPull Requestの作成・更新時にも実行します。
- 定期実行と手動実行の有効化には、workflowがデフォルトブランチに存在する必要があります。このPRは自動でマージしません。
- SecretsやAI APIキーは不要です。API利用・Cloudflare公開・GitHub Pages公開・コードの自動修正・PRの自動作成は行いません。
- workflowの権限はcontents: readのみ。チェックアウト後に認証情報を残しません。

## 確認方法

ローカルではNode.js 24で `node --test tests/*.test.cjs` を実行します。npm installは不要です。
GitHubのActions → Global Parents testsからログと実行サマリーを確認できます。
mainへの承認済みマージ後はRun workflowから手動実行もできます。
失敗通知はGitHubアカウントのActions通知設定で有効にしてください。メールやChatGPTへの自動報告は未設定です。

## 検証範囲と限界

実際のindex.html内のJavaScriptをNode.jsのVMと最小DOMアダプターで実行します。
7種類の英文生成、日付、名前、時刻、未翻訳の注意表示、コピーの成功・失敗、AIへのコピー文、再作成を検証します。
実ブラウザの見た目・モバイル表示・ブラウザ固有のClipboard権限・英訳の品質・公開サイトの稼働確認は対象外です。

## 追加設定

1. リポジトリのActionsが有効で、actions/checkoutとactions/setup-nodeの実行が許可されていることを確認します。
2. PRのCI成功を確認してから、ユーザーの承認によりマージします。定期実行はそれまで開始しません。
3. mainの保護と、このテストを必須チェックにすることを推奨します。設定変更は本PRに含めません。
4. GitHub側の利用枠・課金設定は別途確認してください。有料AI APIは一切使いません。
5. 公開リポジトリでは長期間活動がないと定期実行が無効になる場合があります。Actionsの状態を確認してください。

これは自動テストの第一段階です。AIによる無人のコード改善には、別途実行基盤と認証・費用条件の確定が必要です。
