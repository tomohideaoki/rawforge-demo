# Global Parents 有料需要検証（未公開案 / 2026-11-13）

対象：英語が苦手な日本人保護者。実AI API・新規決済契約を使わない手動提供の需要検証。**現時点では販売開始していない。**

## 検証商品
「学校連絡英文の作成＋意味確認用の日本語文」：1件1,500円（税込・試験価格）。
日本語原文500文字まで、英文1案、確認用日本語1案、修正1回。受付可能な場合のみ24時間以内を目安に納品。学校への送信代行・医療法律判断・緊急対応は対象外。

## 公開前のチェック
- 提供者本人が24時間対応・修正対応可能か確認。
- 決済手段と手数料、キャンセル・返金、個人情報の取扱い、事業者情報等の必要な表示を確認。未確認のまま代金を受領しない。
- 氏名・学校名・病名等は原則不要。保護者の同意を得て最小限の内容だけ受け付ける。
- AI利用の有無、品質確認の方法、納期と免責を明示。完成英文は保護者が確認し自分で送信する。

## 未送信の需要検証原稿
「学校の先生に英語で連絡するたびに時間がかかっていませんか？ 日本語で内容を送ると、学校向けの自然な英文と、意味を確認する日本語文を1セットでお渡しします。1件1,500円（税込）、500文字まで、修正1回。※試験提供の準備中です。正式な受付開始前に、必要な連絡の種類と利用意向を確認しています。」

## 合否の判断
販売前の意向調査は匿名・個人情報不要で10件を目安に収集し、価格提示後に「利用したい」回答が3件以上なら、法令・決済・提供体制確認後に少数件の有料検証を検討。3件未満なら価格・対象課題を再検討。意向回答は購入実績と区別する。

## Plugins準備
役割：日本人保護者向け学校連絡文支援。手順：日本語の事実確認→必要最小限の確認→自然で丁寧な英文→日本語の意味確認文→不足情報を明記。禁止：事実の追加、医療・法律判断、本人に無断の送信、個人情報の公開。参考仕様：docs/translation-connection.md（PR #4、2026-10-19ブランチ版）、experiments/translation-response-adapter.mjs（2026-11-12版）。評価例：入力「今日は家族の予定があるため学校を欠席します」→欠席と家族の予定を保ち、理由を創作しない。合格：意味の一致・余計な情報なし・丁寧な英文・日本語確認文の存在。接続仕様：POST text、認証と課金制限は別途設計。既存カスタムGPTの非公開指示・知識ファイルは未取得。Pluginへの実装・互換性検証・切替は未実施。
