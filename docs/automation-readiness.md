# 追加料金なしの自動検証

`node scripts/automation-check.cjs` で既存テストをまとめて実行し、成功数・失敗名・現行HTMLの既知の未完了項目を日本語で報告する。
テスト失敗・実行エラー・90秒超過は終了コード1。レポートが生成されても失敗を成功扱いにしない。

## GitHubでの実行

新しいworkflowはmain向けPRの作成・更新時に、対象ファイルの変更があれば動く。workflow_dispatchやデフォルトブランチ変更は不要。Draftでも実行対象。mainへのマージなしで確認できる。
公開リポジトリの標準ubuntu-24.04ランナーのみ。privateならジョブをスキップする。依存パッケージのインストール、AI、PAT、Secret参照、artifact・cache保存、デプロイ、リポジトリへの書き込み、新しいscheduleはない。
処理はGitHub上で行われ、起動後に本人のPCを閉じても続く。常時稼働するAIではない。既存daily-tests.ymlの定期実行は変更しない。

## 実行範囲

テストは最小DOMアダプターによるオフライン検証。実ブラウザ・翻訳APIの疎通や課金の検証はしない。HTMLからの未完了項目抽出は固定文字列の検査であり、汎用AI診断ではない。
テスト子プロセスに認証情報を引き継がない。ただしテストそのものをネットワークから隔離するOSサンドボックスではない。未確認コードや外部依存をテストに追加する場合はレビューが必要。

## 次の実装順

1. 既存の翻訳導線を完成させる。現行mainはChatGPTへの手動コピー方式で、CloudflareとのAPI接続コードが存在しない。Workerの成功だけではアプリ全体の完成にはならない。
2. 指定の対象表現へ統一し、申し込み・有料利用の導線を設計する。課金サービスの接続は未承認。
3. Copilotは無料残枠・認証条件が確認できるまで停止。PR #2は未変更・未マージのまま。
4. Instagram・note・アフィリエイトは、原稿作成と公開を分ける。公式連携・無料枠・アカウント権限の確認前に自動投稿を約束しない。
5. FXは開発・検証と実口座取引を分ける。実取引の自動発注はこの開発の対象外で、別途明示的な取引条件と承認が必要。

このPRは自動検証の追加のみで、アプリ本体・翻訳・収益化を完成させるものではない。mainマージ・公開はしない。
