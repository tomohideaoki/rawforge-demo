# Global Parents — 自動収益化・AI社員 実行設計（草案）

状態: **非公開の作業ブランチに保存した計画書**。公開・決済導入・有料API・自動AI実行は未承認であり未実施。

## 目的
英語が分からない日本人保護者が、学校への連絡を簡単に、自然な英語で準備できるサービス。保護者が使うたびに価値を提供し、少ない手動作業で継続的な収益を目指す。収益や完全自動化を保証しない。

## 収益化の仮説（未決定）
1. 無料: 欠席・遅刻などの基本テンプレート、短い日本語説明、英語文、和訳、注意点、短い返信例。
2. 有料候補: 文脈別の追加テンプレート集、返信の言い換え・トーン調整、保存済み文例の管理、保護者向けガイド。
3. 学校向け候補: 保護者向け連絡テンプレートパック、導入支援。学校の正式な承認なく学校名・ロゴを使用しない。

料金、決済事業者、利用制限は、需要検証・運用費の確認後に決める。決済ページや課金を勝手に追加しない。

## 先に検証する価値
- 利用者が最も困る場面: 欠席、遅刻、体調、先生への質問、行事への返信。
- 利用前の悩みと利用後の成果を短いアンケートで確認する（任意・個人情報最小限）。
- 3つの検証指標: テンプレートの使用完了率、役立ったと回答した割合、有料機能への関心表明数。
- 実際の支払意思は、同意を得たヒアリングで確かめる。収益見込みは数字を捏造しない。

## 自動化の順序
A. **既存**: GitHub Actionsの毎日テスト。AIなし・PCを閉じていても動作。
B. **次**: 翻訳APIの失敗原因を安全に調査し、修正案をブランチ・PRにする。Cloudflare本番変更なし。
C. **次**: 公開前の品質チェック（自然な英語、入力検証、エラー表示、アクセシビリティ）。
D. **次**: 無料コンテンツの追加と有料機能の需要検証。
E. **最後**: 予算上限・本人承認・ログ・停止手段を整えた上で限定的なAI実行を試験。

## 重要な制約
- mainへのマージ、Cloudflare公開、決済接続、有料API、定期実行の追加、実際のAI呼び出しは明示的承認まで行わない。
- 学校連絡文には子どもの氏名、病歴、学校名などが含まれうる。個人情報を収集・保存しない設計を優先し、第三者AI送信は分かりやすく説明する。
- AIの出力は誤訳や不適切な敬語がありうるため、送信前に保護者が確認する。
- 自動投稿、スパムDM、無断の営業送信はしない。
- FX自動売買・スワップ運用はGlobal Parentsの収益計画と分離する。実資金の無人取引は行わず、必要なら分析・記録・デモ検証から検討する。
