# Global Parents翻訳接続の確認事項（2026-10-21）

現行mainのサイトには翻訳APIへの接続がありません。一方、Draft PR #4には、AI翻訳ボタンを無効化した状態の接続コードとモックテストがすでにあります。二重開発を避け、PR #4を検証するのが優先です。

## 発見した仕様の差
以前の計画書は「/translate に message と task を送信し、subject・english・japanese を受信」と仮定しています。しかしPR #4のコードは「Workerのルートに text を送信し、english を受信」という構成です。計画書は実APIの仕様を確定したものではありません。

## 既存テストで扱っていること
空入力、文字数上限、同意、HTTPエラー、タイムアウト、二重送信、古い応答の破棄などです。ただしモック試験であり、現在のWorker本番動作や翻訳の意味の正確さは確認できません。

## 次の順序
1. Worker側の現在の入出力仕様を確認。
2. サーバー側の利用制限・費用上限・データの扱いを確認。
3. 既存のオフラインテストを実行して結果を記録。
4. 公開前に翻訳品質を評価。

今回の調査では、実API呼び出し・課金・公開・マージは行っていません。
