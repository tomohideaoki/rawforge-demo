# 10/31までの自動化MVP｜承認待ち計画
更新：2026-10-22。目的は、収益につながる反復作業を自動化し、新事業に使える時間を増やすこと。収益の発生自体は保証しない。

## 最初の稼働対象
Global Parentsの無料テスト自動化を第一候補とする。これは収益化そのものではなく、製品を安定して提供する土台。A8.netとコーチングは原稿・審査・公開の人間確認を残す。

## 最小成功条件
- 承認されたテスト専用ブランチで、追加費用なしのGitHub Actionsが実際に成功する。
- 実行ログから成否と所要時間を確認できる。
- main、Cloudflare本番、SNS、外部API、Secrets、既存テストを変更しない。
- artifact保存、Copilot CLI、有料AI、定期実行は承認がない限り使わない。
- 自動化の実行と、売上発生は別々に報告する。

## フェーズ
10/22〜24: リポジトリのワークフローと権限の確認。実行可能な最小YAML案をレビュー。
10/25〜27: ユーザー承認後に限り、テストブランチにワークフローを追加し、単発実行。
10/28〜30: 実行ログ・費用・安全条件を確認し、継続運用の是非を判断。
10/31: 承認された自動化を1つ稼働開始することを目標。未承認なら稼働させない。

## 収益化の別工程
Global Parents: 有料機能と決済・利用規約・サポート等は未実装。実装・公開前に承認。
A8.net: 提携済み案件、掲載媒体、広告表示の確認が必要。Amazonは対象外。
Coaching: 申込・予約・決済は未連携。提供できるサービスだけを販売する。
XMTrading: 勧誘・自動収益化の対象外。

## 次に必要な承認
『無料・単発・テスト専用ブランチ・本番非変更のGitHub Actions実行』の具体案を提示後に実行承認を得る。
