# 5事業・AI社員運営計画 — 2026-10-20
**状態: 草案。公開・投稿・取引・決済・有料API実行なし。**

## 目的
Global Parents、FX、note、Instagram、アフィリエイトを連携し、少ない手動作業で継続的に価値を届ける仕組みをつくる。収益の保証はしない。

## 5つの役割
| 事業 | 主な成果物 | 収益仮説 | AIが準備できること | 本人承認が必要なこと |
|---|---|---|---|---|
| Global Parents | 学校連絡文・テンプレート | 有料機能・教材 | テスト、文例、PR | 公開、API課金、決済 |
| FX | 相場研究・学習記事 | 教育コンテンツ、将来の運用研究 | 履歴整理、検証レポート | 実資金取引、口座操作 |
| note | 読者の課題を解決する記事 | 単品記事・マガジン | 構成、下書き、校正 | 投稿、販売、価格設定 |
| Instagram | リール・カルーセル・ストーリー | 自社商品・サービスへの集客 | 台本、キャプション、企画 | 投稿、DM送信、外部連携 |
| アフィリエイト | 比較・レビュー・選び方 | 成果報酬 | 比較表の設計、下書き、リンク点検計画 | 提携申請、広告公開、購入 |

## 優先順位
1. Global Parents: 現行AI翻訳ボタンの不具合調査と修正案（本番反映なし）。
2. note: 有料にする前に無料記事で課題と需要を検証。
3. Instagram: note・Global Parentsへの導線を設計。無断DMなし。
4. アフィリエイト: 読者に役立つ製品カテゴリと選定基準を整理。実在商品・価格・報酬は公開前に検証。
5. FX: 実資金自動売買ではなく、過去検証・分析ログ・リスク検証から開始。

## 自動化の共通ルール
- 既存の毎日テスト以外の新しい定期実行は承認まで追加しない。
- mainマージ、Cloudflare公開、SNS/note投稿、アフィリエイト提携、決済、実資金取引は承認なしに行わない。
- 有料API・有料サービスは契約しない。秘密情報や個人情報をログやGitHubに記録しない。
- AI出力は人が確認する。金融情報は利益を保証しない。広告・提携リンクにはPR表記を付ける。
- 自動化の成功指標は売上だけでなく、利用者満足、正確さ、コスト、手動作業削減も含める。

## 最初の30日（実施前の案）
第1週: 各事業の顧客と提供価値を1文で定義、既存素材の棚卸し。
第2週: note記事2本、Instagram投稿5本、アフィリエイト比較記事1本の草案。
第3週: 公開可否を本人が確認。Global Parentsの動作検証、FX検証テンプレート整備。
第4週: 閲覧数・保存数・問い合わせ・使いやすさの結果で改善。売上は実績が出るまで空欄。
