# note × Instagram コンテンツ草案
**未公開。編集・投稿は本人承認後。**

## note 無料記事案 1
**仮タイトル: 「英語が苦手な親が、インターナショナルスクールとの連絡で困ったとき」**

### 導入
学校から英語の連絡が届く。内容は何となく分かっても、失礼のない返事を英語で書くのは難しい。特に欠席や体調の連絡は、短く正確に伝えたい。

### 本文構成
1. まず伝える情報を日本語で整理する（誰が・いつ・何を）。
2. 長い英文より、誤解の少ない短い英文を選ぶ。
3. 丁寧さを保ちつつ、必要のない事情を付け足さない。
4. 送る前に日付・名前・欠席理由の表現を確認する。
5. Global Parentsのような支援ツールを使う場合も、最後は自分で確認する。

### 締め
英語が得意でなくても、伝えたいことを整理すれば学校との連絡は少しずつ楽になる。読者が困った場面を聞き、次の記事に反映する。

## note 無料記事案 2
**仮タイトル: 「忙しい父親が、やりたいことを事業に変える前に決める3つのこと」**
- 誰のどんな困りごとを解決するか。
- 1回だけでも提供できる最小の成果物は何か。
- 続けられる時間・費用・やらないことは何か。
- 最初から「完全自動収益」を約束しない。小さく検証する。

## Instagram カルーセル案（Global Parents）
1枚目: 「学校への英語連絡、何を書けばいい？」
2枚目: 「最初に整理するのは3つ。いつ・誰が・何を。」
3枚目: 「長く書くより、正確に。」
4枚目: 「欠席・遅刻・体調連絡は、伝える順番が大切。」
5枚目: 「英文は送信前に必ず確認。」
6枚目: 「困った連絡場面をコメントで教えてください。」

**キャプション案**
「学校に英語で連絡したい。でも、失礼にならないか不安。そんなときは、まず日本語で伝える内容を整理しましょう。欠席・遅刻・体調など、どの場面で困ることが多いですか？ ※この投稿は一般的な文章作成のヒントです。」

## Instagram リール案（noteへの導線）
冒頭: 「仕事と家庭で忙しい。だけど、自分の事業もつくりたい。」
展開: 「まず決めるのは、誰のどんな困りごとを解決するか。」
締め: 「3つの整理ポイントをnoteの記事にまとめました（公開後に案内）。」

## 投稿前チェック
- 自分の経験と他人の体験を混同しない。
- 誇大な収益・成果の約束をしない。
- 著作物、子どもや学校の個人情報、無許可の写真を載せない。
- 投稿リンクやCTAは公開先が完成してから設定する。
