# Five-business automation roadmap (draft)

No production changes, credentials, API calls, trades, or scheduled workflows authorized by this document.

## note
- Input: approved topics and audience.
- Generate article markdown with fact-check checklist, disclosure and CTA.
- Store as draft in GitHub; publishing requires separate confirmation and a supported integration.

## Instagram
- Generate carousel copy, caption, alt text, and review checklist.
- Verify Meta professional account and supported official publishing permissions before proposing automation.
- Never auto-post without approval.

## Affiliate
- Identify registered ASPs, allowed products, commission rules, disclosure requirements and tracking.
- Prepare a comparison matrix with source/date, pricing, return policy, evidence, and conflict-of-interest note.
- No invented links or affiliate applications.

## FX demo-only EA
- Platform: MT5 demo; broker symbol suffix, spread, time zone and account constraints must be checked.
- Draft deterministic rules: EMA10/20/200, candle close, trend filter, stop-loss, take-profit, spread filter, daily drawdown limit, no-trade on missing data, emergency stop.
- Backtest with out-of-sample period and transaction costs, then forward-test on demo. No real-money trading.
- Track date, symbol, timeframe, setup, entry, SL, TP, spread, reason, result, drawdown, screenshots/notes (no account numbers).

## Approval gates
- Require explicit approval before publication, Meta/API permissions, paid services, secret changes, scheduled actions, merging, Cloudflare deploy, or live trading.
- Do not commit personal data, passwords, tokens, account numbers, or authentication details.
