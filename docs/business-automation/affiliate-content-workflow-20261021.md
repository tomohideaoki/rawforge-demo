# アフィリエイト原稿作成フロー v1｜非公開ドラフト
対象: A8.net、Amazonアソシエイト。Xも候補媒体に追加（アカウントID・接続状況は未確認）。XMTradingは金融法令・適法性確認まで紹介停止。

## 目的と境界
1テーマから note長文 / Instagramカルーセル / X短文を作成する。公開や予約投稿、DM送信、商品購入、アカウント接続はしない。GitHub公開リポジトリなので秘密情報、報酬データ、個人情報、未公開契約内容は保存しない。

## ワークフロー（手動承認付き）
1. テーマ候補を選定（例: 在宅作業環境、仕事の記録・整理、学習・制作に役立つ一般ツール）。
2. 案件の存在・提携承認・対象商品・規約・禁止表現・利用可能媒体をASP画面で確認（未確認なら「調査待ち」）。
3. 比較表に実価格・条件・出典・更新日・実際に使ったかを記入。使っていない商品に体験談を捏造しない。
4. 読者の課題→選択基準→候補比較→デメリット→開示文→次の行動、の順に原稿作成。
5. note/Instagram/Xそれぞれの仕様に合わせた3種類の原稿を作る。
6. 人が事実、権利、広告表示、ASP規約、誤認表現、リンクを確認。
7. 明示的な公開承認後にのみ投稿を検討。自動投稿の実装は別途権限・費用・規約を確認。

## 投稿媒体の役割
note: 比較記事・選び方・注意点。Instagram: 選択基準の要約とnoteへの案内。X: 一つの知見と記事案内。大量同文投稿や無差別DMはしない。

## 広告表示（仮文言）
「広告・アフィリエイトリンクを含む場合があります。購入・契約が成立すると紹介料を受け取ることがあります。」
実際のASP/媒体規約と日本のステマ規制に沿って、投稿ごとに明瞭に表示。表示の有無は記事内容に合わせて確認。

## 最初の3テーマ候補（販売・推薦前）
A 在宅作業を始める人のPC周辺環境：選び方と失敗しやすい点
B 動画・文章制作の作業効率を高める整理方法
C 目標管理のノート・デジタルツール比較
個別商品の推薦・リンク・価格は未確認のため未記載。

## 停止条件
法令・規約不明、提携未承認、リンク未確認、事実未検証、追加課金、外部公開、金融商品勧誘、資格・年齢等の条件未確認。
