# Global Parents: 翻訳API接続仕様とテスト計画
作成日: 2026-10-21 / **提案・未実装・未公開**

## 現状と目的
現行サイトの「AIに渡す文章をコピー」は、文章をコピーする機能。GitHub PagesからCloudflare Workerを呼ぶ処理は未実装。既存の定型文を維持しつつ、別の「AIで英文を作成」機能を将来追加するための仕様をまとめる。Cloudflare Workerの現在のPOST入力・出力形式は未確認なので、以下は**提案**であり実際のAPI契約を示すものではない。

## 画面の動作案
1. 日本語で学校への連絡内容を入力する。
2. ユーザーが明示的に「AIで英文を作成」を押したときだけ、入力内容を送信する。自動送信はしない。
3. 送信前に送信先・プライバシーに関する短い説明を表示。氏名や健康情報などは必要最小限にする。
4. 応答が正常なら、件名・英文・日本語訳を表示。原文の意味を変えたり、欠けた情報を創作したりしない。
5. 失敗時はエラーを表示し、入力内容を残し、既存の定型文とコピー機能を使えるようにする。
6. 送信中はボタンを無効化して重複送信を防ぐ。連続実行には上限を設ける。

## 仮の入出力仕様（未確定）
POST /translate
Request JSON: { "message": "今日は家族の予定があるため、学校を欠席します。", "task": "school-message" }
Success JSON: { "subject": "...", "english": "...", "japanese": "..." }
Error JSON: { "error": "service_unavailable" }
**注意:** Workerの実装に合わせて契約を確定すること。公開前に実コードを確認。レスポンスの構造を検証せずにHTMLへ挿入しない。テキストは textContent で表示し、HTMLとして解釈しない。

## セキュリティと費用
- ブラウザにAPIキー・Secretを置かない。認証情報をGitHubに保存しない。
- CORS許可元は実際のGitHub Pagesのオリジンに限定する。CORSは認証・濫用対策の代替ではない。
- 入力長上限、レート制限、タイムアウト、サーバー側検証を設ける。
- AI実行に費用が発生する可能性があるため、無料枠と課金設定が確認できるまで実行・公開しない。
- 送信データの保存有無・保持期間は実装と契約を確認してから明示する。未確認の「保存しない」は約束しない。
