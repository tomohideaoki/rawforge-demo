# DaddyzTimeClub｜Xから誘導するnote記事（未公開原稿）
タイトル：家族との時間を増やしたい父親へ。まず「今週の15分」を予定に入れる
家族との時間を増やしたいと思っても、仕事や家事で一週間が過ぎることがあります。そんなとき、最初から生活を大きく変える必要はありません。

## 1. 何をしたいかを一つ決める
一緒に本を読む、散歩する、話を聞く。家族にとって無理のない活動を一つ選びます。

## 2. 先に予定に入れる
「時間ができたら」ではなく、実行できそうな15分をカレンダーに入れます。相手の予定も尊重します。

## 3. 一週間後に振り返る
実行できたかだけでなく、楽しかったこと、難しかったことを確認。できなければ時間や方法を変えます。

## 道具はあとから
紙のカレンダーでもスマホの予定表でも構いません。買い物をする前に手持ちの方法を試すのがおすすめです。必要に応じて道具を比較するときは、価格、家族の使いやすさ、続けやすさを確認しましょう。

最後に：今週、家族と何をする15分をつくりますか？
