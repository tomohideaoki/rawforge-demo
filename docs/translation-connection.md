## 停止状態

`index.html` の `GP_TRANSLATION_ENABLED` はfalse。翻訳ボタンは無効で、イベントを直接発火してもfetchしない。ページ表示や入力変更でもリクエストしない。既存の文章コピーは使用できる。
このフラグは準備コードの誤実行防止であり、課金上限・認証・サーバー側利用制限を実装するものではない。ユーザーがHTMLを書き換えることまで防げない。
有効化・本番公開はこのPRに含めない。無料枠・サーバー側の利用制限・実API契約・CORS・本人のAI実行承認を確認する前に有効化しない。

## 有効化後を想定した動作

送信同意と手動クリックが揃ったときだけ、自由入力欄の文字列のみを送る。名前や他のフォーム値を自動付加しない。Cookie・認証ヘッダーは送らない。自動再試行や別プロバイダーへの切替はない。
失敗しても元の英文を保持。二重クリックを抑止し、処理中に入力・英文・同意が変更された場合は古い結果を反映しない。結果はtextarea.valueへ代入し、HTMLとして実行しない。日本語訳を生成したようには表示しない。
