# Goal Setting Coaching｜コーチ用マニュアル v0.1（非公開・未承認）
## 基本姿勢
コーチは答えを押し付けず、質問・要約・確認で本人の判断を支援する。成果を保証しない。診断や治療、金融・法律助言をしない。
## 事前準備
本人に「今回決めたいこと」「現状」「使える時間」を任意で聞く。パスワード・機密情報・健康情報など不要な個人情報を収集しない。面談記録を公開GitHubに保存しない。
## 60分進行
0–5分：目的、守秘の範囲、今日の到達点を確認。
5–15分：現状把握。「今何に時間を使っていますか」「何が止めていますか」。
15–30分：目標を1つに絞る。「いつまでに何ができれば達成ですか」「本人が制御できる部分は何ですか」。
30–40分：障害と選択肢。「予定が崩れた場合の最小行動は？」。
40–52分：7日間の計画。「いつ・どこで・何を・何分行う？」。無理な計画を避ける。
52–60分：本人に要約してもらい、行動1つと振り返り日を確認。
## 面談で使う質問例
「本当に変えたいことは何ですか」「何をしないと決めますか」「その目標が現実的だと判断できる根拠は？」「最初の一歩を10分で始めるなら？」
## 納品テンプレ
目標：／期限：／達成判定：／今週の行動：／実施日時：／障害：／代替行動：／振り返り日：
## 品質チェック
顧客自身の目標か、測定可能か、実行時間が現実的か、最初の一歩が明確か、同意なく長期契約へ誘導していないか。
## 試行と改善
有料販売前に模擬セッションを実施し、時間配分・質問のわかりやすさ・成果物を検証。顧客の個人情報はGitHubに置かない。
